# Product Vision — ARCHITAK Platform

## Purpose

Build a modern digital platform for **ARCHITAK**, an interiors-first design studio in Vyttila, Kochi — not a WordPress theme clone.

## Positioning

**Interiors-first Kochi studio**, with architecture as a capability in Services. Tagline: **CREATED TO CREATE**.

## Platform goals

1. Visually exceptional public website (editorial, spatial, imagery-led)
2. Secure administration and CMS
3. Lead and enquiry management
4. Foundation for future operations (clients, estimates, invoices, BOM, procurement, inventory)
5. Scalable modular monolith — no premature microservices

## Brand cues

- Monochrome triangle mark, geometric **A**, high contrast
- Premium architectural editorial — not generic SaaS, Bootstrap, or default shadcn look
- Firm photography as primary visual focus

## Success criteria

| Area | Outcome |
|------|---------|
| Public | Distinctive, fast, SEO-friendly, crawlable by search and AI agents, accessible |
| Admin | Secure, role-aware (later), operable |
| Technical | TypeScript-first, documented, migration-driven, env-only secrets, RLS-aware |
| Evolution | Portfolio → CMS + leads → operations without rewrite |

## Non-goals (V1)

- Cloning the current WordPress/Elementor site
- Full CRM, invoicing, inventory
- Turborepo / microservices
- Global Three.js / GSAP
- Making the R2 bucket blindly public
