# Implementation Roadmap

## Phase 0 — Discovery and planning

Docs, ADRs, Cursor rules. **Done when** this documentation set exists.

## Phase 1 — Foundation

Next.js scaffold, tokens, env, static admin auth, Supabase clients, storage types, security headers, Dependabot. No marketing pages.

## Phase 2 — Design system

Typography, color, primitives, `/dev/design-system`.

## Phase 3 — Public MVP + discovery

Home, work, project detail, studio, services, contact, sitemap, robots, llms.txt, SEO.

## Phase 4 — Immersive

Selective GSAP / Lenis / optional 3D with fallbacks.

## Phase 5 — Admin CMS

Projects, media (public/private), enquiries, SEO fields; migrate to Supabase Auth when multi-user needed.

## Phase 6 — Hardening

RLS audit, CSP tighten, `media.architak.in` Worker (public/ only), WordPress cutover redirects.

## Phase 7 — Operations

Clients, engagements, estimates, invoices, BOM, procurement, inventory — files under `private/` by default.
